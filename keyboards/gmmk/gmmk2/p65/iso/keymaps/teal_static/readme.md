# GMMK 2 ISO Dumb Keymap

Minimal ISO keymap for a German GMMK 2 Compact.

- Keeps the stock base layer.
- Limits the Fn layer to F1-F12, mute, volume down/up, and play/pause.
- Forces a static soft yellow-green RGB matrix colour on boot.
- Highlights Caps Lock and active Fn keys in red.
- Disables mouse keys.
